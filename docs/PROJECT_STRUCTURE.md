# 專案結構與檔案用途說明

本文件詳細說明 `boardgame-web` 專案中各個檔案與目錄的用途及其必要性。

## 📂 根目錄 (Root)

| 檔案/目錄 | 用途說明 | 必要性 |
| :--- | :--- | :--- |
| `serve.py` | **程式進入點**。負責啟動 Web 伺服器 (Waitress/Flask)。 | ✅ **核心必要** |
| `boardgame_system.py` | **系統外觀 (Facade)**。提供統一介面供 API 呼叫核心服務。雖然是舊架構留存，但目前被多個路由引用。 | ✅ **核心必要** |
| `boardgame-bot-*.json` | **Google Sheets 憑證**。用於存取後端資料庫 (Google Sheets)。 | ✅ **核心必要** |
| `start.ps1` | **啟動腳本**。方便在 Windows 環境下快速啟動伺服器。 | ✅ **工具必要** |
| `requirements.txt` | **依賴套件清單**。定義專案所需的 Python 套件。 | ✅ **核心必要** |
| `requirements-dev.txt` | **開發依賴清單**。定義開發/測試所需的額外套件 (如 pytest)。 | ✅ **開發必要** |
| `pytest.ini` | **測試設定檔**。設定 pytest 的執行參數。 | ✅ **測試必要** |
| `.env.example` | **環境變數範例**。提供設定檔的模板。 | ✅ **文件必要** |
| `.gitignore` | **Git 忽略清單**。避免將敏感或暫存檔案上傳至版控。 | ✅ **版控必要** |
| `Dockerfile` | **Docker 設定**。用於容器化部署。 | ✅ **部署必要** |
| `.dockerignore` | **Docker 忽略清單**。優化 Docker 映像檔建置。 | ✅ **部署必要** |
| `README.md` | **專案說明文件**。 | ✅ **文件必要** |

## 📂 應用程式核心 (app/)

負責 Web 應用程式的主要邏輯。

| 檔案/目錄 | 用途說明 | 必要性 |
| :--- | :--- | :--- |
| `__init__.py` | **App 工廠**。初始化 Flask 應用程式與套件。 | ✅ **核心必要** |
| `extensions.py` | **擴充套件**。初始化 Flask-CORS 等擴充功能。 | ✅ **核心必要** |
| `config/` | **設定檔目錄**。包含開發、測試、生產環境的設定。 | ✅ **核心必要** |
| `blueprints/` | **路由模組**。包含 API、Admin、Main 等頁面的路由邏輯。 | ✅ **核心必要** |
| `middleware/` | **中介軟體**。包含錯誤處理 (Error Handlers) 等邏輯。 | ✅ **核心必要** |

## 📂 核心邏輯 (core/)

負責與資料與外部服務互動的商業邏輯。

| 檔案/目錄 | 用途說明 | 必要性 |
| :--- | :--- | :--- |
| `sheets_client.py` | **資料庫客戶端**。負責與 Google Sheets 溝通。 | ✅ **核心必要** |
| `game_service.py` | **桌遊服務**。處理桌遊的借還、查詢邏輯。 | ✅ **核心必要** |
| `member_service.py` | **會員服務**。處理會員資料邏輯。 | ✅ **核心必要** |
| `bgg_service.py` | **BGG 服務**。整合 BoardGameGeek API。 | ✅ **核心必要** |
| `bgg_api_client.py` | **BGG API 客戶端**。底層 API 呼叫實作。 | ✅ **核心必要** |
| `demo_data.py` | **演示資料**。提供 Demo 模式下的假資料，避免依賴外部 API。 | ✅ **功能必要** |
| `cache.py` | **快取機制**。實作簡單的記憶體快取。 | ✅ **效能必要** |
| `utils.py` | **工具函式**。共用的輔助函式。 | ✅ **核心必要** |
| `constants.py` | **常數定義**。定義全域常數。 | ✅ **核心必要** |
| `exceptions.py` | **自定義例外**。定義專案專屬的錯誤類型。 | ✅ **核心必要** |
| `decorators.py` | **裝飾器**。如快取裝飾器等。 | ✅ **核心必要** |

### 總結

目前專案中的檔案結構非常精實，所有檔案都有其明確的職責。

- **沒有發現多餘的垃圾檔案** (已刪除 `style_original.css`)。
- **`boardgame_system.py`** 雖然是舊架構，但為了保持相容性必須保留。
- **`core/demo_data.py`** 為了支援無網路或無 API Key 的開發環境，建議保留。

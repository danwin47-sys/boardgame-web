# 🗺️ Boardgame-Web 開發路線圖

## 📊 專案現況

**當前版本：** v3.0 (Gallery Wall & BGG Ranks Integration)

### ✅ 已完成功能

| 模組 | 功能 | 狀態 |
|------|------|------|
| **桌遊管理** | 借還操作、狀態追蹤、歷史記錄 | ✅ 完成 |
| **BGG 整合** | 遊戲連結、搜尋、熱門排行、推薦 | ✅ 完成 |
| **BGG Ranks** | 離線資料庫、30萬+遊戲查詢 | ✅ 完成 |
| **Gallery Wall** | 視覺化展示、多條件過濾 | ✅ 完成 |
| **管理後台** | 批次操作、權限控管 | ✅ 完成 |
| **會員管理** | 搜尋、借閱記錄 | ✅ 完成 |
| **成就系統** | 成就追蹤、視覺化呈現 | ✅ 完成 |
| **Email 通知** | 關鍵更新通知 | ✅ 完成 |
| **BGG 加入** | 從 BGG 搜尋並加入遊戲到館藏 | ✅ 完成 |

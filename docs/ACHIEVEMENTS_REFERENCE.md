# 桌遊社成就系統設計參考

> **狀態：** 規劃階段，暫未實作
> **建立日期：** 2025-12-04
> **目的：** 保留成就系統設計供未來參考

## 概述

此文檔記錄了桌遊社成就系統的完整設計方案，包含 60+ 項成就，涵蓋會員在借閱、教學、參與社課等方面的活動追蹤和獎勵機制。

---

## 成就系統設計（60+ 項成就）

### 成就類別總覽

1. 📚 **借閱成就**（10項）- 基礎借閱行為和時間挑戰
2. 🎓 **教學成就**（9項）- 教學活動和多元性
3. 🎪 **社課參與**（8項）- 出席記錄和全勤挑戰
4. 🎯 **分類探索**（8項）- 不同遊戲類型探索
5. ⏰ **時間挑戰**（6項）- 連續性和速度挑戰
6. 👥 **社交成就**（6項）- 團體互動和推薦
7. 🏆 **特殊成就**（9項）- 獨特活動和里程碑
8. 🏅 **榮譽成就**（6項）- 稀有高難度成就

## 技術實作建議

### 數據儲存

#### Google Sheets 工作表結構

**1. 成就記錄工作表**

```
| 會員姓名 | 成就ID | 成就名稱 | 當前進度 | 目標值 | 完成% | 解鎖時間 | 成就等級 |
```

**2. 教學記錄工作表**

```
| 會員姓名 | 桌遊名稱 | 教學日期 | 參與人數 | 參與者名單 | 備註 |
```

**3. 社課出席工作表**

```
| 會員姓名 | 出席日期 | 社課主題 | 是否主持 | 備註 |
```

### 後端實作

#### 核心模組 (`core/achievements.py`)

- 定義所有成就規則
- 成就檢查邏輯
- 進度計算
- 成就等級系統（銅、銀、金、白金）

#### API 端點 (`app/blueprints/api/achievements.py`)

- `GET /api/achievements` - 取得所有成就定義
- `GET /api/achievements/user/<name>` - 取得用戶成就進度
- `GET /api/achievements/leaderboard` - 取得排行榜
- `POST /api/achievements/teaching` - 記錄教學
- `POST /api/achievements/attendance` - 記錄出席
- `POST /api/achievements/check` - 檢查並更新成就

### 前端實作

#### UI 組件

- 成就列表展示（已解鎖/未解鎖/進行中）
- 進度條和完成百分比
- 成就解鎖動畫（煙火效果）
- 分類篩選器
- 排行榜展示
- 成就浮動通知

#### 互動功能

- 點擊成就查看詳情
- 成就分享功能
- 排行榜實時更新
- 教學和出席記錄表單

## 未來擴展建議

### 成就等級系統

- 🥉 **銅級** - 基礎成就（1-3 星）
- 🥈 **銀級** - 中級成就（4-6 星）
- 🥇 **金級** - 高級成就（7-9 星）
- 💎 **白金級** - 傳奇成就（10+ 星）

### 成就點數系統

- 每個成就根據難度給予點數
- 累積點數可兌換獎勵
- 點數排行榜

### 社交功能

- 成就分享到社群媒體
- 成就比較（與其他會員）
- 成就挑戰（發起挑戰邀請其他人）

### 季節性成就

- 春季限定成就
- 暑期特別成就
- 聖誕/新年成就
- 社團週年慶成就

## 💻 程式碼範例

### 範例 1: 修改元件屬性

**來源：** Virginia Tech SKILL教材

```lisp
; 修改所有nfet3和pfet3的bulk節點
procedure(cb()
  let((cv)
    cv = geGetEditCellView()
    
    ; 處理nfet3
    foreach(inst cv~>instances
      when(inst~>cellName == "nfet3"
        inst~>bulk = "vss!"
      )
    )
    
    ; 處理pfet3
    foreach(inst cv~>instances
      when(inst~>cellName == "pfet3"
        inst~>bulk = "vdd!"
      )
    )
  )
)
```

**用途：** 批次修改電晶體的bulk連接

---

### 範例 2: 控制流程

**來源：** Cadence官方文件

```lisp
; if條件判斷
if( voltage > threshold
  then
    printf("Voltage is high\n")
  else
    printf("Voltage is low\n")
)

; when - 單向條件
when( errorFlag
  printf("Error detected!\n")
  handleError()
)

; unless - 反向條件
unless( dataValid
  printf("Data is invalid\n")
)

; case - 多重選擇
case( signalType
  ("digital" processDigital())
  ("analog" processAnalog())
  ("mixed" processMixed())
  (t printf("Unknown signal type\n"))
)
```

### 範例 3: 迴圈操作

```lisp
; for迴圈
for( i 1 10
  printf("%d " i)
)

; foreach迴圈
foreach( element '(a b c d e)
  printf("%s " element)
)

; while迴圈
let((counter 0))
  while( counter < 5
    printf("Count: %d\n" counter)
    counter = counter + 1
  )
)
```

---

### 範例 4: 列表操作

```lisp
; 建立列表
myList = list(1 2 3 4 5)

; 取得第一個元素
firstElement = car(myList)  ; => 1

; 取得其餘元素
restElements = cdr(myList)  ; => (2 3 4 5)

; 連接列表
combinedList = append(list(1 2) list(3 4))  ; => (1 2 3 4)

; 取得列表長度
listLength = length(myList)  ; => 5

; 存取特定位置
thirdElement = nth(2 myList)  ; => 3 (0-based index)
```

---

### 範例 5: 字串處理

; 字串連接

### 範例 6: 檔案讀寫

```lisp
; 讀取檔案
let( (port nil line nil)
  port = infile("data.txt")
  when(port
    while( (line = gets("" port))
      printf("Read: %s\n" line)
    )
    close(port)
  )
)

; 寫入檔案
let( (port nil)
  port = outfile("output.txt" "w")
  when(port
    fprintf(port "Line 1\n")
    fprintf(port "Line 2\n")
    close(port)
  )
)
```

## 🎓 學習路徑建議

### 初學者路徑

1. **第一週：基礎語法**
   - 閱讀Cadence SKILL User Guide前3章
   - 練習基本資料型別和變數
   - 在CIW中測試簡單指令

2. **第二週：控制結構**
   - 學習if, when, unless, case
   - 練習for, while, foreach迴圈
   - 從GitHub下載範例程式碼研究

3. **第三週：列表和字串**
   - 掌握car, cdr, append等函數
   - 練習字串操作
   - 撰寫簡單的資料處理腳本

4. **第四週：檔案I/O**
   - 學習讀寫檔案
   - 練習資料匯入匯出
   - 建立實用工具腳本

---

### 中級路徑

1. **資料庫操作**
   - 學習db系列函數
   - 練習開啟和修改CellView
   - 建立簡單的Layout自動化腳本

2. **GUI開發**
   - 學習hiCreateAppForm
   - 建立自訂對話框
   - 整合到Cadence工具列

3. **PCell開發**
   - 研究GitHub上的PCell範例
   - 建立簡單的參數化元件
   - 學習pcDefinePCell函數

---

### 進階路徑

1. **SKILL++**
   - 物件導向程式設計
   - 類別和繼承
   - 進階資料結構

2. **整合專案**
   - 參與開源專案

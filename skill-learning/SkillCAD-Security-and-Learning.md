## 資料安全性問題

### ❓ SkillCAD會竊取我的設計資料嗎？

**簡短回答：不會。**

### 🔒 為什麼不會？

#### 1. **本地執行架構**

```
SkillCAD的運作方式：
┌─────────────────────────┐
│ 您的電腦 / 伺服器       │
│ ┌─────────────────────┐ │
│ │  Cadence Virtuoso   │ │
│ │  ┌───────────────┐  │ │
│ │  │  SkillCAD     │  │ │  ← 在本地執行
│ │  │  (SKILL code) │  │ │
│ │  └───────────────┘  │ │
│ └─────────────────────┘ │
└─────────────────────────┘
         ↓
   本地檔案系統
   (您的設計資料)
```

**關鍵點：**

- ✅ SkillCAD是SKILL程式碼
- ✅ 在Virtuoso內部執行
- ✅ 所有操作都在本地
- ✅ 不需要連接外部伺服器

---

#### 2. **SKILL語言特性**

```lisp
; SKILL是解釋型語言
; 直接存取Virtuoso資料庫
; 不需要也無法傳輸資料到外部

procedure(exampleSkillCADOperation()
  let((cv))
    ; 直接操作本地cell view
    cv = geGetEditCellView()  
    
    ; 所有操作都在本地記憶體
    ; 沒有網路傳輸
  )
)
```

---

#### 3. **商業信譽**

**SkillCAD的開發商有充分理由保護資料：**

- 💼 **商業聲譽**：資料外洩會毀掉公司
- 📜 **法律責任**：違反NDA會面臨巨額訴訟
- 🏢 **客戶是大公司**：Intel、Samsung等不會容忍風險
- 🔐 **產業標準**：EDA工具必須符合安全規範

---

### 🔍 SkillCAD能存取什麼？

#### 可以存取（設計目的）

```
✅ Layout幾何資訊（public API）
✅ Cell view屬性（public API）
✅ 層級結構（public API）
✅ 設計規則（tech file）
✅ 本地檔案系統（需要權限）
```

#### 不能或不需要存取

```
❌ 網路連線（SKILL沒有）
❌ 外部伺服器（不需要）
❌ 加密通訊（沒有功能）
❌ 您的其他檔案（除非明確授權）
```

```
□ 資料傳輸說明
□ 第三方分享政策
□ 審計權利
□ 保密條款
```

## SkillCAD會竊取設計資料嗎？

### 官方答案：**不會**

### 原因分析

#### 1. **技術上不需要**

SkillCAD的價值在於**自動化Layout操作**，不是資料收集。

```
SkillCAD的商業模式：
賣軟體授權 → 收授權費 ✅
竊取設計資料 → 違法且無用 ❌
```

---

#### 2. **法律風險極高**

```
竊取資料的後果：
├─ 刑事責任（商業間諜罪）
├─ 民事賠償（可能數億美元）
├─ 公司破產
└─ 個人入獄
```

**沒有公司會冒這個風險。**

---

#### 3. **產業慣例**

**EDA產業的資料處理標準：**

- ✅ 所有操作本地化
- ✅ 不收集用戶資料
- ✅ 遵守NDA和保密協議
- ✅ 定期安全審計

**類似工具：**

- Cadence自己的工具也是如此
- Synopsys、Mentor等大廠同樣標準

```lisp
procedure(myAutoAlign(instList direction)
  ; 這是您自己的演算法
  let((positions sorted))
    ; 收集位置
    positions = mapcar(lambda((inst) inst~>xy) instList)
    
    ; 排序
    sorted = sort(positions 
      if(direction == "horizontal"

      )
    )
    
    ; 重新排列
    ; ... 您的實作邏輯
  )
)
```

### 📖 學習案例：合法 vs 非法

#### ✅ 合法範例

**情境：** 您想開發自己的bus routing工具

```lisp
; 步驟1：理解需求（透過使用SkillCAD）
; "原來使用者需要快速建立平行的多條線"

; 步驟2：查閱Cadence文件
; 學習dbCreatePath、dbCreateVia等API

; 步驟3：自己設計演算法
procedure(myBusRouter(startPt endPt numTracks spacing layer)
  let((tracks yOffset))
    ; 您自己的邏輯
    yOffset = 0
    
    for(i 0 numTracks-1
      ; 建立每一條track
      dbCreatePath(
        geGetEditCellView()
        list(layer "drawing")
        list(
          startPt + list(0 yOffset)
          endPt + list(0 yOffset)
        )
        spacing
      )
      
      yOffset = yOffset + spacing * 2
    )
  )
)
```

**這是完全合法的！** 您：

- 用的是公開API
- 演算法是自己寫的
- 沒有複製SkillCAD的程式碼

#### ❌ 非法範例

```lisp
; 這是：
```

```lisp
;******************************************************************************
; 我自己的「線選擇」工具
; 靈感來自V-Editor，但演算法完全自創
;******************************************************************************

procedure(myLineSelect(startPt endPt)
  let((line objs selected))
    ; 建立選擇線
    line = list(startPt endPt)
    
    ; 找出與線相交的物件（我自己的演算法）
    objs = geGetEditCellView()~>shapes
    selected = nil
    
    foreach(obj objs
      when(lineIntersectsShape(line obj)  ; 自己寫的函數
        selected = cons(obj selected)
      )
    )
    
    ; 選擇這些物件
    geSelectObject(selected)
    
    printf("Selected %d objects\n" length(selected))
    selected
  )
)

; 自己實作的相交檢測
procedure(lineIntersectsShape(line shape)
  ; 您的幾何演算法
  ; ...
)
```

**這是合法的！** 因為：

- ✅ 概念受啟發（合法）

- ✅ 使用公開API（合法）
